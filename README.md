This program is a console-based account creation and login system written in Java. When launched, it prompts the user to create an account by entering a username and password that meet specific security requirements — usernames must be longer than 3 characters and contain at least one number, while passwords must exceed 8 characters and include both a number and an uppercase letter. Once an account is created, the username and password are encrypted using a Caesar cipher with a shift of 10 and saved to a local database file (database.txt) along with a unique account number. The user is then prompted to log in, and has up to 3 attempts before the program restarts. After each failed attempt, a 5-second countdown timer runs, and any input entered during the countdown is ignored to prevent accidental characters from interfering with the next login prompt. The program runs in a continuous loop, allowing new accounts to be created after each session ends.
